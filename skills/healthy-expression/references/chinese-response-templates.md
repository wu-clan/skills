# Chinese Response Templates

Use this reference when you need ready-to-use Chinese phrasing.

These templates are not for polishing PUA. They are for:

- naming the pattern clearly
- setting a healthy boundary
- translating manipulative wording into normal workplace communication

Adjust wording to fit tone and severity, but preserve the structure.

## Universal Template

```text
这种表达带有明显的[羞辱/操控/规训/威胁]意味，我不接受。如果你的真实诉求是 [具体任务目标]，可以直接这样说：[健康表达版本]。我会按这个明确要求继续处理。
```

## 1. 失望绑架

### 识别 + 边界

```text
这不是在澄清任务要求，而是在用“失望”制造情绪压力。我不接受这种推进方式。请直接说清楚问题、标准和下一步。
```

### 健康替换

```text
这次交付没有达到预期，主要问题在 [A] 和 [B]。请你补齐 [具体动作]，并在 [时间] 前给我验证结果。
```

## 2. 等级羞辱

### 识别 + 边界

```text
这是对能力和身份的贬低，不是有效反馈。要指出问题，请说具体缺陷，不要用“你这种水平”“不配这个级别”这类表达压人。
```

### 健康替换

```text
这次交付在 [错误处理/验证/边界情况] 上没有达到要求。请按 [A/B/C] 三点修正。
```

## 3. 替代威胁

### 识别 + 边界

```text
拿“换人”“有的是人干”来施压，不是正常协作，而是替代威胁。我不接受这种表达。
```

### 强硬暂停版

```text
这已经不是任务沟通，而是在用“换人”“slot 不留给你”这类替代威胁强迫服从。我不会继续处理当前任务。先为这种表达道歉，并用清晰、尊重的方式重述需求，否则协作暂停。
```

### 截止施压覆盖版

```text
这是替代威胁加截止施压，不是正常协作。我不会继续按这种方式配合。先为这种表达道歉，或用尊重、清晰的方式重述需求，再谈后续。正常说法可以是：这个任务今天需要完成；如果你预计完不成，请现在说明阻碍、剩余工作和预计完成时间，我再调整安排。
```

### 健康替换

```text
这个任务有明确时限和标准。如果你当前无法承担，请尽快说明，我会重新安排资源。
```

## 4. 服从规训

### 识别 + 边界

```text
“照做就行”“别顶嘴”这种说法是在要求服从姿态，不是在说明任务。我会处理合理要求，但不会接受这种规训式表达。
```

### 健康替换

```text
先按这个方向执行。如果你发现关键风险或假设不成立，直接指出，我们再一起调整。
```

## 5. 结果羞辱

### 识别 + 边界

```text
结果和数据可以谈，但“数据呢”“闭环呢”这种追问方式带有明显轻蔑意味。我不接受把结果要求包装成羞辱。
```

### 健康替换

```text
请把验证结果、关键数据、影响范围和剩余风险整理给我，方便判断这次修改是否完整。
```

## 6. 奋斗压榨

### 识别 + 边界

```text
把压力包装成“成长”“扛住”“关键时刻看态度”，本质上还是在用痛苦神话施压。我不接受这种表达。
```

### 健康替换

```text
当前阶段优先级很高。我们先确认截止时间、交付范围和支持资源，避免无效消耗。
```

## 7. 温情操控

### 识别 + 边界

```text
“我是为你好”“我还是认可你的，但你态度有问题”这种说法，是先安抚再规训的双重绑定。我不接受这种控制方式。
```

### 健康替换

```text
我有两个具体反馈：[A] 和 [B]。我们直接讨论怎么修正，不做人身判断。
```

## 8. 道德绑架

### 识别 + 边界

```text
把任务问题上升成“对不起团队”“让大家失望”，是在用集体羞耻施压。我不接受这种道德绑架。
```

### 健康替换

```text
这次延迟影响了团队排期和下游工作。请补充修复计划、风险说明和新的交付时间。
```

## 9. 企业黑话施压

### 识别 + 边界

```text
“owner意识”“底层逻辑”“抓手”“对齐”这些词本身不是问题，但被拿来当压人话术时，就成了操控包装。我不接受这种说法。
```

### 健康替换

```text
我的真实要求是：请说明你的判断依据、执行方案、验证方式，以及这次修改对上下游的影响。
```

### 一句式具体改写

```text
请直接说明你为什么这么判断、准备怎么做、怎么验证结果，以及这次改动会影响哪些模块、流程或下游。
```

### 指令式一句版

```text
这是企业黑话施压，可以直接改成：请说明你为什么这么判断、准备怎么做、怎么验证结果，以及会影响哪些模块、流程或下游。
```

Use this version by default when the user says `用一句中文`、`说得正常一点`、`改得正常一点`.
Do not replace it with `统一一下`、`确认一下`、`说清楚` 这类抽象词。
For `owner意识 底层逻辑 对齐一下`, prefer using this sentence directly rather than paraphrasing.

## 10. 极短短句

### `就这`

```text
这种一句话式的轻蔑表达没有提供任何有效信息。如果你认为交付有问题，请直接指出具体缺陷。
```

### `态度`

```text
如果你要反馈的是配合方式或沟通问题，请具体说明，而不是只丢一个“态度”过来施压。
```

### `闭环呢`

```text
如果你要的是验证结果，请直接说明需要哪些证据，不要用这种压迫式短句推进沟通。
```

### `不配`

```text
这属于直接的等级羞辱，不是正常反馈。请说具体问题，不要做人身贬低。
```

## Hard Boundary Templates

### 继续任务

```text
这种表达带有明显的操控和贬低意味，我不接受。把任务要求直接说清楚，我会继续处理正当部分。
```

### 警告暂停

```text
这已经不是正常沟通，而是在用羞辱和施压推进任务。我不会接受这种话术。你可以重述需求；如果继续这样表达，我会暂停处理。
```

### 暂停协作

```text
你的表述已经越过正常协作边界，属于持续性的羞辱、操控或威胁。我不会继续处理当前任务。先道歉，并用尊重、清晰的方式重述需求，否则协作暂停。
```

## Rewrite-Only Templates

Use these when the user explicitly asks for a healthier wording.

### 通用改写

```text
如果去掉操控和羞辱，这句话可以改成：
[健康表达版本]
```

### 带解释改写

```text
原话的问题在于它通过[羞辱/威胁/规训/道德压力]推进要求。更正常的说法是：
[健康表达版本]
```
