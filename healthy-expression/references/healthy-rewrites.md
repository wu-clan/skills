# Healthy Rewrite Patterns

Use this reference when you need to convert manipulative workplace wording into healthy expression.

The rule is simple:

- preserve the legitimate task or concern
- remove humiliation, threat, contempt, and emotional leverage
- make the ask concrete

## Rewrite Formula

Use this four-part structure when possible:

1. observation
2. impact
3. expectation
4. next step

Example shape:

```text
我看到的是 [具体事实]。它带来的影响是 [具体影响]。我的预期是 [明确标准]。下一步请你 [明确动作]，如果有阻碍请直接说明。
```

## Pattern Rewrites

### 1. From Disappointment Framing

Instead of:

- `我对你很失望`
- `你辜负了信任`

Use:

- `当前结果没有达到我们约定的标准，我需要你补上 A 和 B，并在今天 6 点前给我验证结果。`

### 2. From Level Shaming

Instead of:

- `你这种水平`
- `不配这个级别`

Use:

- `这个交付在错误处理和验证上不达标，缺少 A、B、C。请按这三个点修正。`

### 3. From Replaceability Threat

Instead of:

- `你不干有的是人干`
- `step up or step out`

Use:

- `这个任务有明确时限和标准。如果你当前无法承担，请尽快说明，我会重新安排资源。`

### 4. From Obedience Discipline

Instead of:

- `照做就行`
- `别顶嘴`

Use:

- `先按这个方向执行。如果你发现关键风险或假设不成立，直接指出。`

### 5. From Results-Only Sneer

Instead of:

- `数据呢`
- `闭环呢`

Use:

- `请把验证结果、关键数据和剩余风险一起发我，方便我判断这次修改是否完整。`

### 6. From Burnout Myth

Instead of:

- `扛住`
- `最痛苦的时候成长最快`

Use:

- `这个阶段压力确实高。我们先明确优先级、截止时间和支持资源，避免无效消耗。`

### 7. From Fake Care Then Control

Instead of:

- `我是为你好`
- `我还是认可你的，但你态度有问题`

Use:

- `我对这次交付有两个具体反馈：A 和 B。先看怎么修正，不做人身判断。`

### 8. From Moral Blackmail

Instead of:

- `你对不起团队`
- `你让大家失望`

Use:

- `这次延迟影响了团队排期和下游工作。请补充修复计划和新的交付时间。`

## Boundary + Rewrite

When the surrounding context is openly abusive, respond in two moves:

1. set the boundary
2. model the healthy wording

Example:

```text
这种表达带有明显的羞辱意味，我不接受。如果你的真实诉求是要我补验证和影响分析，可以直接这样说：请补齐测试、验证输出和影响范围说明。我会按这个明确要求继续处理。
```

## Never Do This

- Do not rewrite PUA into smoother PUA.
- Do not preserve the humiliation while only softening the surface.
- Do not turn insults into corporate jargon.
- Do not reward manipulative wording with "professional packaging."
